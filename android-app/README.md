# XiaoMusic Android App 客户端 🎵

专为 **XiaoMusic** 打造的原生 Android 音乐客户端，支持局域网直连 Python 后端服务，替代手机端网页，提供更丝滑的 B 站歌曲搜索、实时下载进度展示与手机本地硬件级无损流媒体播放。

---

## 📱 核心功能特性

1. **灵活的服务端连接配置**：
   - 支持自由设定服务端 IP（默认 `192.168.6.114`）与端口（如 `58090`）；
   - 内置一键网络连通性检测与版本校验，跨网段地址智能重定向。
2. **B 站音乐全网搜索与下载**：
   - 直通后端的 Bilibili 官方 Wbi 免登录搜索；
   - 卡片式展示高清封面图、视频标题、UP主、时长；
   - **实时下载进度条**：点击下载后原地展开 0%~100% 动态进度与状态（正在抓取音频流 -> FFmpeg 转码中 -> 下载完成），下载完成后自动同步至本地曲库。
3. **手机原生流媒体播放器**：
   - 基于 **AndroidX Media3 (ExoPlayer)** 原生音频引擎打造；
   - 支持本地歌曲秒级流式点播，支持后台保活与播放暂停；
   - 底部常驻微型播放控制条，随时掌握歌曲播放进度。
4. **现代化 UI 架构**：
   - 100% 采用 **Jetpack Compose + Material 3** 声明式 UI 构建。

## 🛠️ 技术选型

| 模块 | 技术选型 | 说明 |
| :--- | :--- | :--- |
| **编程语言** | Kotlin (1.9.22) | 现代 Android 标准开发语言 |
| **UI 框架** | Jetpack Compose + Material 3 | 声明式响应式界面 |
| **网络请求** | Retrofit 2 + OkHttp 3 + Gson | RESTful 异步 API 请求与日志追踪 |
| **图片加载** | Coil Compose | 异步加载 B 站封面缩略图 |
| **音频引擎** | AndroidX Media3 (ExoPlayer 1.2.1) | 行业级高性能流媒体解码与播放 |
| **架构模式** | MVVM + Coroutines Flow | 响应式状态管理 |

## 🚀 如何在 Android Studio 中打开与运行

1. 打开 **Android Studio**，选择 **Open**；
2. 浏览并选中 `c:\develop\xiaomusic\android-app` 目录打开；
3. 等待 Gradle 同步完成；
4. 连接真实 Android 手机（开启 USB 调试）或启动 Android 模拟器；
5. 点击工具栏的绿色运行按钮 **Run 'app'** 即可编译安装；
6. 在 App 底部的 **「服务设置」** 页面输入您的电脑内网 IP（默认 `192.168.6.114`）与端口（`58090`），点击「保存配置并测试连接」，显示绿色成功标志后即可畅享使用！
